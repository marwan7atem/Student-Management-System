# 📘 Student Management System (C Project)

The **Student Management System** is a C program designed to manage student records efficiently. It demonstrates strong usage of **linked lists, structs, pointers, and core programming concepts**.

This project was developed as part of the **Embedded Systems Diploma at Edges for Training**.

---

## 🚀 Features

* ➕ **Add a Student** – Store new student records.
* 📋 **Display All Students** – View all records in the system.
* 🔍 **Search by ID** – Quickly find a student.
* ✏️ **Update Student Information** – Modify existing student data.
* ❌ **Delete a Student** – Remove a record by ID.
* 📊 **Calculate Average GPA** – Compute overall student performance.
* 🏆 **Find Highest GPA** – Identify top-performing student.

---

## 🛠️ Tech Stack

* **Language:** C
* **Concepts Used:** Linked Lists, Structs, Pointers, Loops, Conditions
